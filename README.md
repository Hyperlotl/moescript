# OWOscript
The most kawaii esolang!<br>
It has a "unique" (totally not difficult to type) script

## Installation
```bash
npm install -g owoscript
```

## Usage
```bash
owo foo.OwO
oworun bar.OwO
```

## Example
```OwOscript
[OWO/main]
<UWU/main>
<:P>
(:O/Hello )
(:O/World!)
<\:P>
<\UWU>
```
